# Mood Music Player

## Project Overview
A Java-based music player that recommends songs and motivational quotes based on the user’s mood (e.g., sad, happy) and language preference.

## Features
- Select your current mood.
- Choose a language.
- Get related songs and motivational quotes.
- User-friendly interface.

## Tools & Technologies
- Java
- GUI (Swing or JavaFX)
- File handling for songs and quotes

## How to Run
1. Open the project in your Java IDE (e.g., Eclipse, IntelliJ).  
2. Compile and run `Main.java`.  
3. Follow the on-screen instructions to select mood and language.
